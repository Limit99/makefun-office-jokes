A tiny, deterministic program for the make.fun competition
"Make the AI Judge Laugh: Office Jokes". It writes exactly one joke
about office life to `/output/entry.txt`:

> I love my job's flexible hours: I can choose any sixty hours a
> week I like, as long as they're the ones my calendar already
> chose for me.

The program checks this competition's 1–199 character gate itself
before writing. No network, no randomness: every run produces the
same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
